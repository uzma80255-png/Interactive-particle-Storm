# 🌌 Interactive Particle Storm

An interactive 3D particle visualization controlled through real-time hand gestures using computer vision.

## ✨ Features

- 🌌 3,000 interactive particles
- 🖐️ Real-time hand tracking
- 👆 Finger-count based particle colors
- 🤏 Pinch gesture interaction
- 💥 Pinch-and-release particle explosion
- ✋ Two-hand gesture controls particle scale
- 🔄 Hand movement controls particle rotation
- 📷 Real-time webcam input
- 📊 Live hand, finger, charge and FPS indicators

## 🎨 Finger Gesture Controls

| Fingers Detected | Particle Color |
|------------------|----------------|
| 0 | White |
| 1 | Red |
| 2 | Blue |
| 3 | Green |
| 4 | Purple |
| 5 | Rainbow |

## 🤏 Pinch Interaction

Pinching the thumb and index finger charges the particle system.

When the pinch is released after sufficient charge, the particles explode outward and gradually return to their original formation.

## ✋ Two-Hand Interaction

Using two hands allows the particle system to dynamically scale based on the distance between the hands.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Three.js
- MediaPipe Hands
- WebGL
- Webcam / Camera API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the project using Live Server.
4. Allow webcam access when prompted.
5. Show your hand to the camera and interact with the particle system.

## 🎯 Project Purpose

This project explores the combination of 3D graphics and computer vision to create an interactive browser-based visual experience controlled through natural hand gestures.
